# 报表操作手册

> 文档作用：说明报表设计、发布、浏览和大屏维护操作。
>
> 作者：DAMU
>
> 创建时间：2026-07-25

## 报表设计

菜单路径：`数据报表 -> 报表设计器`。

先确认数据源、字段口径和访问范围，再创建报表。设计时设置查询条件、表格或图表组件、汇总方式和打印布局；保存后使用小范围数据校验总数、时间范围和空值展示。发布给业务人员前，确认报表不暴露超出角色权限的数据。

## 大屏设计

菜单路径：`数据报表 -> 大屏设计器`。

创建大屏后添加图表、文本、指标和数据集，设置刷新间隔和展示尺寸。发布前在目标分辨率下预览，并核对数据刷新、过滤条件和访问权限。大屏是展示层，不应成为人工录入或修改业务数据的入口。

## 运行限制

项目中报表组件和大屏设计器的启用状态由运行配置决定。页面可访问但无法保存、预览或加载数据时，先检查报表服务配置、数据源权限和浏览器控制台，再联系实施人员处理。

## 核心流程：设计、发布与核验报表

**适用角色：** 报表管理员、经营分析人员。**前置条件：** 已确认数据源、字段口径、授权范围及刷新频率；数据集已完成最小权限配置。

菜单路径：`报表管理 -> 报表设计器`。

1. 进入设计器后先新建报表，命名中包含业务主题和统计粒度，例如“销售日报-按客户”。
2. 配置数据集、参数和筛选条件，明确日期范围、组织范围、状态口径和空值处理方式；不要直接使用超大范围的明细查询。
3. 添加表格、指标卡或图表，设置字段映射、汇总逻辑、排序和打印布局；预览时用已知业务单据验证总量和金额。
4. 保存并设置访问角色，使用非管理员账号验证可见范围；发布后记录版本、发布人和数据口径。
5. 异常数据先追溯到源业务单据和数据集，再修改报表配置；报表不得作为修改业务数据的入口。
