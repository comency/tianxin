# 全模块图文操作手册优化设计

> 文档作用：定义 RuoYi-Vue-Pro 全模块操作手册的细化范围、截图规范和验收标准。
>
> 作者：DAMU
>
> 创建时间：2026-07-25

## 目标

将现有 15 份模块概览手册升级为可执行的图文操作手册。每个关键业务流程均提供真实管理端页面截图，并完整说明前置条件、菜单路径、操作步骤、结果核验和常见异常。

## 范围

保留并完善 `docs/00-使用前准备与通用约定.md` 至 `docs/14-即时通讯操作手册.md`。覆盖系统管理、ERP、工作流、会员、支付、商城、CRM、报表、公众号、AI、IoT、MES、WMS 和即时通讯。

业务闭环至少包括：

- 系统管理：组织与用户建立、角色授权、菜单授权、字典维护、日志核查。
- ERP：基础资料、采购订单、采购入库、付款、销售订单、销售出库、收款、库存调拨、库存盘点。
- 工作流：模型发布、流程发起、待办审批、实例核查。
- CRM：线索转化、客户与联系人维护、商机推进、合同与回款。
- 商城与会员：商品发布、订单处理、售后、会员资料和积分操作。
- MES 与 WMS：生产准备、工单与报工、入库追溯；收货、发货、移库、盘点和库存追溯。
- 其他模块：以实际菜单中可执行的配置、创建、查询或处理闭环为准。

## 图文结构

每个关键流程使用统一结构：

1. 适用角色与前置条件。
2. 菜单路径。
3. 编号操作步骤，写明页面按钮、字段和关键校验。
4. 截图，紧随对应步骤显示。
5. 结果核验，说明如何确认数据、状态或下游单据。
6. 常见异常与处理边界。

截图仅使用本地已启动的管理端真实页面。若演示环境没有业务数据，截图展示真实的列表、表单或确认界面，并在文字中说明需要先准备的数据。不得生成界面示意图，不得写入账号密码、令牌、密钥或个人敏感信息。

## 图片存放与命名

在 `docs/assets/screenshots/` 下按手册编号与模块建目录，例如 `docs/assets/screenshots/02-erp/`。

图片文件名使用小写英文和短横线，格式为 `<流程>-<序号>-<页面>.png`，例如 `purchase-order-01-list.png`、`purchase-order-02-form.png`。手册使用相对 Markdown 路径引用图片，并为每张图提供简短中文图注。

## 外部服务边界

支付、公众号、AI、IoT、即时通讯、短信、邮件和对象存储等模块的页面操作与外部服务实际生效分开说明。手册明确所需的应用凭据、回调地址、网络连通性或设备接入等前置配置，但不记录真实密钥。

## README 更新

`docs/README.md` 增加图文手册使用约定、截图目录说明和各手册的关键流程覆盖概览，继续作为所有操作文档的统一入口。

## 验收标准

- 15 份模块手册和通用约定均保持 UTF-8 编码。
- 每个定义的关键业务流程都有逐步操作说明和至少一张真实页面截图。
- 所有图片相对链接可解析，图片非空，Markdown 文档链接可解析。
- 文档中的菜单、页面和流程与现有 Vue3 管理端模块结构一致。
- 外部依赖功能具有清晰的配置前提和验证边界。
