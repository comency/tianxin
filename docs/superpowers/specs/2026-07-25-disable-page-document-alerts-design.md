# 页面文档提示全局移除设计

> 文档作用：定义管理后台页面顶部文档提示的移除范围与验证方式。
>
> 作者：DAMU
>
> 创建时间：2026-07-25

## 目标

移除管理后台所有页面顶部由 `DocAlert` 组件展示的“【标题】文档地址：URL”轻提示，不修改业务页面、菜单、数据或普通文档跳转链接。

## 方案

在 `src/components/DocAlert/index.vue` 中移除可视渲染内容及其仅用于展示的逻辑。各业务页面保留 `<doc-alert>` 调用，无需修改约 230 个页面文件；组件不再产生 DOM，因此所有调用页面不再占用顶部空间。

## 范围边界

- 包含：所有 `<doc-alert>` 页面级提示。
- 不包含：登录页、用户菜单、错误消息及其他独立的文档链接。
- 不包含：业务功能、接口、路由、权限、环境变量和数据变更。

## 验证

1. 在变更前执行静态断言，确认组件当前包含 `el-alert`，得到预期失败。
2. 修改组件后重复断言，确认组件不再渲染 `el-alert` 或文档提示文字。
3. 执行前端 TypeScript 类型检查。
4. 通过浏览器访问菜单管理等页面，确认页面顶部不再显示文档提示，列表和查询功能仍可用。
