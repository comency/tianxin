# Disable Page Document Alerts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the documentation alert banner from every management page while preserving existing page calls and unrelated links.

**Architecture:** `DocAlert` is the single shared rendering component used by page templates. The change makes this component render no DOM, so its approximately 230 callers require no edits. Static assertions and TypeScript checking verify the removed render path does not introduce compilation errors.

**Tech Stack:** Vue 3, TypeScript, Element Plus, vue-tsc, pnpm.

## Global Constraints

- All modified text files must use UTF-8.
- Modify only the shared `DocAlert` component and the approved documentation files.
- Do not change login, user-menu or other standalone documentation links.
- Do not alter existing user changes in unrelated MES API and view files.

---

### Task 1: Disable the shared document alert renderer

**Files:**
- Modify: `yudao-ui/yudao-ui-admin-vue3/src/components/DocAlert/index.vue`
- Test: inline Node static assertion against `src/components/DocAlert/index.vue`

**Interfaces:**
- Consumes: Existing `<doc-alert title="..." url="..." />` calls generated by page templates.
- Produces: A no-op Vue component named `DocAlert` that renders no banner or layout spacing.

- [ ] **Step 1: Run the failing static assertion**

```powershell
node -e "const fs=require('fs'); const source=fs.readFileSync('src/components/DocAlert/index.vue','utf8'); if (/<el-alert|文档地址/.test(source)) { throw new Error('DocAlert still renders a document banner') }"
```

Expected: command fails with `DocAlert still renders a document banner` because the current component contains the alert markup.

- [ ] **Step 2: Replace the component with the minimal no-op implementation**

```vue

<script setup lang="ts">
defineOptions({ name: 'DocAlert' })
</script>
```

- [ ] **Step 3: Run the static assertion again**

```powershell

```

Expected: command exits with code `0`.

- [ ] **Step 4: Run the front-end type check**

```powershell

```

Expected: command exits with code `0` and reports no TypeScript errors.

- [ ] **Step 5: Verify all page callers remain in place and no document banner markup remains**

