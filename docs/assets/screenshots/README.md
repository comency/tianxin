## 命名规则

截图文件采用 `<流程>-<序号>-<页面>.png` 格式，例如：
`purchase-order-01-list.png`、`purchase-order-02-form.png`。

所有图片均来自本地管理端真实页面。截图前应隐藏账号密码、令牌、密钥、二维码和个人敏感信息；如页面未配置演示数据，可保留真实的空列表、表单或提示状态，并由手册说明数据前置条件。
