## 阅读顺序

先阅读 [使用前准备与通用约定](00-使用前准备与通用约定.md)，再按工作职责选择业务手册。系统功能手册适用于平台管理员；ERP、CRM、商城、会员和支付手册适用于经营与财务人员；MES 与 WMS 手册适用于生产和仓储人员；AI、IoT、公众号、即时通讯手册适用于集成管理员。

各手册按“前置条件、菜单路径、编号步骤、页面截图、结果核验、常见异常”组织。截图均来自本地管理端真实页面，目录和命名规则见[操作手册截图目录](assets/screenshots/README.md)。页面没有演示数据时，手册会明确需要预先准备的主数据、权限或外部服务配置。

## 关键流程覆盖

系统功能手册覆盖组织权限、字典和日志核查；ERP 覆盖采购、销售、库存和资金闭环；工作流覆盖模型发布、发起和审批；CRM 覆盖线索到回款；商城、会员和支付覆盖商品、订单、会员资产和交易处理；MES、WMS 覆盖生产与仓储作业闭环。其他集成模块以真实页面的配置、发布、查询或处理闭环为准，并会标明与外部服务的边界。

## 使用原则

菜单是否可见、按钮是否可用，取决于当前账号的角色、数据权限和租户范围。涉及删除、审核、撤销、库存变动、收付款或对外发送的操作，应先在测试数据或业务负责人确认后执行。各模块中的外部服务能力必须先完成相应配置，不能以页面可见作为已可投产的依据。
