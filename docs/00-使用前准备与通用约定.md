# 使用前准备与通用约定

> 文档作用：说明所有模块共用的访问、权限、列表、表单和审批操作规则。
>
> 作者：DAMU
>
> 创建时间：2026-07-25

## 访问与登录

本地全模块启动成功后，管理后台入口为 `http://127.0.0.1:80`，后端接口与 Swagger 入口为 `http://127.0.0.1:48080/swagger-ui`。使用系统管理员分配的账号登录；本地配置关闭了图形验证码，但不会因此绕过账号、密码、租户和角色校验。

首次使用时确认浏览器能访问首页、个人中心和消息入口。若登录后菜单缺失，先检查当前租户、角色和菜单权限，不要直接修改业务数据。

## 菜单与数据权限

1. 在左侧菜单中按模块进入列表页；通过顶部标签页在多个页面间切换。
2. 操作按钮由菜单权限控制，数据范围由角色的数据权限控制。
3. 切换租户后，重新查询列表，避免在错误租户下维护数据。
4. 无权查看或编辑时，记录菜单路径、账号、时间和报错信息，交由系统管理员调整权限。

## 列表、筛选与分页

列表页通常提供关键字、状态、日期范围和关联对象筛选。先缩小筛选条件，再打开详情核对；导出前应按相同条件查询，防止导出超出授权的数据。分页只影响当前查看范围，不改变查询条件。

## 新增、编辑、删除与状态变更

新增前先维护被引用的基础资料，例如组织、客户、供应商、产品、仓库或字典项。编辑已提交、已审核或已产生下游单据的数据前，应先判断业务状态；此类记录通常需要撤回、作废或通过红冲类单据修正。

删除只适用于未被引用的草稿或基础资料。删除前确认影响范围；对已发生库存、资金、审批或外部回调的记录，使用业务模块提供的关闭、取消、退货或冲销流程。

## 导入、导出与附件

下载模板后按模板列名填写，保留必填列和字典值格式。导入前使用少量数据试导，处理错误行后再执行批量导入。导出文件应按公司数据分级要求保存；上传附件不得包含与业务无关或敏感的个人信息。

## 审批与消息通知

需要审批的单据应在提交前完成必填项、明细和附件校验。发起人可在“我的流程”查看实例状态；审批人在“待办任务”处理通过、驳回、转办或委托。驳回后按意见修改并重新提交；撤回仅适用于尚未完成且系统允许撤回的实例。

## 数据安全与问题反馈

不要共用账号或在生产环境测试支付、消息推送、设备指令等外部动作。出现接口错误时，记录请求时间、菜单、操作对象编号和提示内容；管理员可结合操作日志、访问日志和任务日志定位问题。

## 标准操作闭环

任何业务模块均按“准备 -> 录入 -> 提交或确认 -> 执行下游动作 -> 查询核验 -> 留存凭据”执行。以采购为例，产品、供应商、仓库和结算账户准备完成后，先录入采购订单；到货后执行采购入库；付款后登记付款单；最后用库存明细、应付记录和付款单号交叉核对。不要跳过前置资料或以直接修改余额、库存替代业务单据。

### 操作前检查清单

1. 确认当前租户、当前登录人及角色与业务归属一致。
2. 确认主数据可选且处于启用状态，例如客户、供应商、产品、仓库、账户或流程模型。
3. 为单据准备可追溯的业务编号、日期、金额、数量、附件和经办人信息。
4. 对会产生库存、资金、审批、消息或外部调用的操作，先确认状态、影响对象和撤销方式。

### 操作后核验清单

1. 返回列表，按单号、名称或创建时间检索，确认新记录可查且状态正确。
2. 打开详情，核对表头、明细、数量、金额、关联对象和操作日志。
3. 存在下游动作时，核对下游单据是否正确引用来源单据，且没有重复创建。
4. 对导出、通知、支付、设备指令等外部结果，保留回执、流水号或错误提示作为凭据。

## 常见页面提示处理

| 提示或现象 | 优先检查项 | 处理方式 |
| --- | --- | --- |
| 菜单或按钮不可见 | 角色、菜单权限、租户 | 由管理员补充授权后重新登录或刷新菜单。 |
| 下拉框没有可选数据 | 主数据状态、数据权限、上下游关系 | 新增或启用主数据，并确认当前账号可见。 |
| 提交后不能编辑或删除 | 单据状态、审批、下游引用 | 使用撤回、作废、退货、退款或反向单据修正。 |
| 列表显示暂无数据 | 查询条件、所属范围、分页 | 先点击重置，再按创建时间和责任人检查。 |
| 外部服务调用失败 | 凭据、回调地址、网络、供应商状态 | 不重复提交，先记录业务单号和错误信息后排查配置。 |
